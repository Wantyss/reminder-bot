# Reminder Bot

Telegram-бот для напоминаний на Python (aiogram 3).

## Возможности

- Добавление напоминаний текстом
- Гибкий ввод времени: `15:30`, `+30m`, `2026-10-20 09:00`
- Список активных напоминаний
- Удаление напоминаний
- Хранение в SQLite
- Работа через SOCKS5-прокси
